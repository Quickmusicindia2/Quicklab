# Quicklab Android starter

The Android module is intentionally minimal and designed as a starting point for a complete editor UI.

## Current contents
- `MainActivity.kt` with a simple Compose UI
- placeholder project structure for timeline, upload, and export UI

## Run locally
Open the folder in Android Studio and run the app on an emulator or device.

## Planned UI
- Home screen for projects
- Video picker and project editor
- Timeline with trim/split controls
- AI suggestions drawer
- Export settings
