# Contributing to Quicklab

Thanks for your interest in Quicklab.

## Ways to contribute
- Report bugs and suggest features
- Improve docs and architecture notes
- Build Android UI and handling code
- Add backend APIs and media jobs
- Help with AI pipelines and model evaluation

## Development setup

### Prerequisites
- Docker and Docker Compose
- Python 3.12+
- Android Studio (for app work)
- Git

### Local development
```bash
git clone https://github.com/Quickmusicindia2/Quicklab.git
cd Quicklab
docker compose up --build
```

Backend API will be available at:
- http://localhost:8000/
- http://localhost:8000/health

## Pull request process
1. Create a feature branch
2. Add tests for bug or feature
3. Run the relevant checks locally
4. Open a pull request with a clear summary

## Code style
- Python: black, ruff, isort
- Kotlin: ktlint preferred

## Community
Please follow the project code of conduct and be respectful in discussions.
